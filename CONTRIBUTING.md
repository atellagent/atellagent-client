# Contributing

Thanks for your interest in Atellagent.

**We are not accepting external code contributions at this time.** Pull requests will be closed without review. This is not a judgment on the contribution — we simply cannot accept third-party code into this repository right now.

This repository is source-available under a proprietary license, not open source. See `LICENSE.md`.

## What we do want

**Bug reports** — open a GitHub issue. Include the client library version (current release is **0.9.0**), what you expected, what happened, and how to reproduce it if you can.

**Security vulnerabilities** — email security@atellagent.com. Do not open a public issue. See `SECURITY.md`.

**Feature requests and feedback** — open a GitHub issue, or email us. We read them.

**Questions** — open a GitHub issue.

## Why contributions are closed

Accepting external code without a contributor license agreement in place would create ownership ambiguity in a codebase covered by pending patent applications. Rather than put a CLA process in front of you before we have the capacity to run one properly, we have closed contributions for now.

This may change. If it does, we will update this file.
