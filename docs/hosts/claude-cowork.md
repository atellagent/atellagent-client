# Claude Cowork capability — deferred

Claude Cowork support is deferred and is not currently available. This client
does not support Cowork: the Claude Code command-hook adapter and its
installation templates do not apply to Cowork, and it makes no model-input,
tool, route-mode, subscription, or enforcement coverage claim for it.

Any Cowork integration requires its own public host-contract review,
identity model, failure behavior, installation path, and conformance tests.
